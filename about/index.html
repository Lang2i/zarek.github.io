枫煜 Zarek

物联网安全研究者 · 硬件渗透爱好者 · 工具造轮子的人
拆固件、抓无线、找调试口，然后把过程写成能复现的文字。

固件分析 无线协议 硬件渗透 编译器

我是谁

一个把「拆开看看里面是什么」当成日常的人。

通信背景出身，所以看设备时习惯先问一句：它的信号往哪儿走？空口上飞的是什么？报文怎么组、怎么解。这个视角让我在无线那一层比大多数人走得更深——不只是抓到包，而是能从调制、帧结构一路读到应用层的明文。

主攻物联网安全，具体来说是把那些看起来封闭的智能硬件打开——读它的 Flash、找它的调试口、抓它空中的无线包，看看厂商到底在里面放了什么，以及哪些地方本该加锁却没加。

不写「十分钟入门」这类内容。这里发布的每一篇，都是我自己在真实设备上跑通过、踩过坑、能复现的流程。

在做的事

固件分析

binwalk 拆包、文件系统还原、后门与硬编码凭据排查，从二进制里还原出厂商的疏忽。

无线协议

BLE、Zigbee、Sub-GHz 的嗅探、重放与伪造。手里有 ChameleonUltra，MQTT 侧用 Mosquitto 搭靶场。

硬件渗透

UART / JTAG 调试口定位、SPI Flash 直接读取，从物理层拿到最高权限。

通信与协议

从空口信号到报文结构：抓包、解帧、还原应用层协议，理解它为什么这样设计、又在哪一步可以被打断。

造工具

基于 LLVM 自研 Vane 语言（类 C 语法，面向嵌入式与脚本场景），以及单文件纯前端的 HTML PPT 工具 HPT。

技术栈

C / C++ LLVM Linux Nim Lua Shell binwalk Ghidra 逻辑分析仪 UART / JTAG / SPI BLE / Zigbee / Sub-GHz TCP/IP MQTT 信号分析

技术之外

技术不是我的全部。真正让我愿意花掉整个晚上的，往往是这几件事：

摄影

镜头是我另一双眼睛。拍得最多的是电路板的纹路、天线的弧度、深夜实验室的灯——那些在被我拆开之前的样子。

编程

写代码是我理解世界的方式。从脚本到编译器，把想法变成一个能跑起来的东西，这个过程本身就足够上瘾。

动手

焊台、示波器、一堆飞线。喜欢能摸到的东西，也相信只有亲手拆过，才算真的懂。

术数

梅花易数、小六壬、大六壬。喜欢的是那套「取象—类比—推演」的思路：从一个卦、一个时辰里，把散落的信息串成一条能自洽的线。

拆硬件和起卦，其实是同一件事——都在找一个系统里看不见的规律。前者靠示波器，后者靠象数。

一路走过来

现在
物联网安全 · 系统化攻坚
从「能扫描」推进到「能利用」：不再满足于跑通现成脚本，而是理解每一个漏洞为什么成立、怎么稳定复现。
进行中
Vane 语言
用 C/C++ 基于 LLVM 实现的一门语言，类 C 语法、模块系统、fn 语法、type:name 参数、可与 C 链接，目标场景是嵌入式与脚本。
进行中
HPT · HTML PPT
单文件纯前端的在线幻灯片编辑器：实时编辑、HTML 导出、演示模式，用浏览器替代传统 PPT。
持续
B 站「枫煜Zarek」
把 IoT 安全的学习过程做成视频：固件分析、无线协议、硬件渗透。不露脸，不放动画，只讲技术本身。
